🛡️ Role Explanations

  • 👨‍✈️ Super Admin Ultimate control over all assets. Can modify Masjid profiles, adjust finances, edit prayer timings, post bulletins, write scholars' articles, and manage user accounts.
  • 👨‍💻 Standard Admin Can manage general content (articles, announcements, gallery) and insert/modify ledger entries, but is restricted from editing or deleting other administrator accounts.
  • ✍️ Editor Can post announcements and publish scholastic articles. Restricted to read-only for financial books, and has absolutely zero control over security or timing grids.
